# 待发布选题

> [!note]
> 本文件是跨业务方向的成熟候选池。仅收录已通过灵感筛选、可供用户选择的题目；不是按早中晚的发布排期。

## 候选卡模板

~~~markdown
### 选题｜简短名称

- 状态：可推荐 / 待核验 / 已采用
- 业务方向：
- 目标客户：
- 经营场景：
- 核心痛点：
- 可承接服务：
- 入选依据：用户需求 / 覆盖缺口 / 客户咨询 / 服务交付 / 历史延展 / 竞品观察
- 核验状态：常青场景 / 已官方核验 / 待核验
- 关联历史内容：
- 差异说明：
- 来源灵感：
- 最近推荐日期：
~~~

用户提出选题需求后，先扫描历史内容库，再从本文件、各业务选题池和灵感库中筛选，输出 5 个场景不重复的方案。只有实际发布且收到明确归档指令后，才将状态改为“已发布”并写入历史内容库。
