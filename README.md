# 广州小张说财税｜视频号内容生产库

本仓库用于运营“广州小张说财税”微信视频号的内容资产与生产流程，服务广州本地创业者和中小微企业的公司注册、代理记账及企业基础财税需求。

## 三层架构

```text
项目规则与 Agent
        ↓
四项独立 Skills
        ↓
账号专属内容库
```

| 层级 | 职责 | 路径 |
| --- | --- | --- |
| 项目规则 | 账号事实来源、任务路由、阶段控制与安全边界 | `AGENTS.md` |
| 项目 Agent | 判断当前阶段、调用 Skill、传递已确认信息 | `.codex/agents/video-account-operator.toml` |
| 灵感录入 | 保存原始灵感、同行内容、图片文字或反馈 | `.codex/skills/idea-intake/` |
| 选题规划 | 扫描本账号资产、查重并生成候选选题 | `.codex/skills/topic-planning/` |
| 文案生成 | 为已确认主题创作合规视频号图文 | `.codex/skills/video-copywriting/` |
| 发布归档 | 在双重确认后写入正式历史内容 | `.codex/skills/publish-archive/` |
| 内容库 | 本账号长期事实、历史内容与业务资产 | `内容库/` |

## 内容库

`内容库/00-首页与维护规则/账号基本定位.md` 是账号定位、业务范围、目标客户、地域、内容目标与表达边界的唯一主要事实来源。

| 目录 | 用途 |
| --- | --- |
| `00-首页与维护规则/` | 账号定位、表达规则、固定选项和归档规范 |
| `01-历史内容/` | 已发布且已明确归档的事实记录，用于查重与覆盖判断 |
| `02-内容地图/` | 按业务、客户、痛点和内容类型查看覆盖情况 |
| `03-选题规划/` | 灵感库、候选选题和业务方向选题池 |
| `04-内容复盘/` | 重复检查、内容缺口、月度复盘与定位变化 |
| `05-内容素材库/` | 标题、案例、风险场景、政策资料等写作素材 |

## 使用方式

- “保存这条同行内容” → `idea-intake`：只创建独立灵感笔记。
- “根据当前内容库给我 5 个选题” → `topic-planning`：扫描本账号历史和资产后输出候选。
- “用第 3 个选题写文案” → `video-copywriting`：继承已确认选题并交付文案。
- “这条已经实际发布，请归档” → `publish-archive`：仅在同时收到发布事实与明确归档指令后写入历史库。

各阶段完成即结束，不会自动流转到下一阶段。确认文案不等于已发布；`01-历史内容/` 只保存实际发布且明确要求归档的内容。

## 内容边界

- 不混用其他账号的业务、客户、地域、历史内容、选题池、素材或文案规则。
- 政策、税率、期限、处罚、办理流程、平台规则和地方政策等确定性信息，须核验当前有效官方来源。
- 不编造政策、案例、数据或处罚结果；不承诺结果，不提供规避监管表达。
