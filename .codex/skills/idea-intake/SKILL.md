# 灵感录入

仅负责原始灵感、竞品内容、用户想法、图片文字和客户反馈的结构化录入。保存成功后结束；不得自动生成选题、扫描历史、写文案或归档。

## 输入处理

- 用户提供文字：原样写入“用户文字”，不改写、不总结。
- 用户提供图片：只提取可读文字写入“图片文字提取”，不保存、嵌入或链接图片本身。
- 图片文字无法完整识别时，保留可读部分并标记“文字识别不完整”；不补写推断。
- 图文混合时，分别保留用户文字原文与图片文字提取。
- 数据表现、原链接和备注仅在用户材料中出现时记录。

## 独立笔记规则

1. 每条灵感建立一篇笔记，保存至 `内容库/03-选题规划/灵感库/YYYY/YYYY-MM/`。
2. 文件名为 `YYYY-MM-DD｜简短名称.md`；名称描述可识别场景，不直接照搬竞品标题。无法判断时使用“待分析灵感”加序号。
3. Frontmatter 固定记录 `title`、`tags`、`source_type`、`status`、`created`、`updated`；初始 `status` 一律为“待分析”。
4. 仅保存本次提供的原文、图片文字和明确备注；不补充目标客户、主题、业务线、服务关联、结论或选题建议。
5. `选题灵感收集.md` 只作索引和模板说明，不保存多条灵感正文。
