# 历史内容库读取规则

## 位置

知识库根目录：`内容库/`；正式历史内容：`01-历史内容/YYYY/YYYY-MM/`。

## 选题前读取规则

1. 每次用户要求选题时，重新列出 `01-历史内容` 中全部 Markdown 文件，不复用上次清单。
2. 解析全部历史笔记的 `title`、`publish_date`、`business_line`、`theme`、`content_type`、`audience`、`pain_scene`、`content_goal` 和 `status`。
3. 阅读最近 30 条笔记正文，以及与候选题相同主题、客户场景或服务机会的历史笔记。
4. 读取账号基本定位、固定选项库、内容维护说明、内容缺口分析、重复选题检查、选题灵感收集、灵感库全部笔记、待发布选题及相关业务选题池。
5. 单篇历史笔记与索引、复盘文件冲突时，以当前历史笔记为准；复盘与内容地图只用于辅助判断。
6. 无法可靠读取或解析历史库时，说明阻碍，不输出正式选题。

## 使用边界

- `01-历史内容` 是已发布内容、去重和覆盖判断的唯一事实来源；灵感库和选题池只能提供候选线索。
- 历史记录不能证明当前政策有效；涉及政策、税率、期限、处罚、平台规则或办理流程时，必须另行核验当前官方来源。
- 不在内容库保存密码、Cookie、验证码或其他登录凭据。
